# 🤖 AI Interview Preparation Assistant

An interactive interview preparation web application built with Python and Streamlit.

The application helps students and job seekers practice interview questions, analyze their answers, and receive instant feedback.

## 🚀 Features

- 👤 Candidate name input
- 💼 Role-based interview practice
- 🎯 Technical and HR interview modes
- 🧠 NLP-based concept matching
- 📊 Answer scoring
- 💡 Instant feedback
- 📝 Answer word count
- 📈 Question-wise performance tracking
- 🏆 Overall interview score
- 🔄 Option to start a new interview

## 💼 Supported Roles

- Data Analyst
- Python Developer
- AI/ML Intern

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Regular Expressions (Regex)
- Basic NLP / Keyword Matching

## 🧠 How It Works

The application provides interview questions based on the selected role and interview type.

When the candidate submits an answer, the system:

1. Processes the answer using text analysis.
2. Identifies relevant concepts and keywords.
3. Calculates an answer score.
4. Generates feedback based on the detected concepts.
5. Tracks performance across questions.
6. Displays an overall interview score.
